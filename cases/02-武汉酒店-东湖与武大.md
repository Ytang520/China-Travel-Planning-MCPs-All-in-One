# 案例 2：武汉酒店（东湖、武汉大学 8 站内）

使用 `travel-mcp-gateway` 完成的一次真实酒店收集。结果表在同目录：[武汉酒店_东湖与武大8站内_20261003.xlsx](武汉酒店_东湖与武大8站内_20261003.xlsx)。

## 用户请求

use the travel-mcp-gateway。我 10.2~10.4 计划在武汉旅游，希望找到合适的酒店，该酒店需要近地铁站。考虑到我主要想去 东湖 和 武汉大学 游玩，因此从这两个地点往外，分别搜寻分别只离它们只有 8 站的地铁站，去重后，针对每家地铁站筛选 40家酒店，按离地铁站从近到远排序。要求房间是：双人房，价格在 250~400之间。收集好所有的酒店后，整理为 excel 表供我审查。

## 结果表里的查询条件

表由各站 `hotel_ctrip_searchHotels` 结果整理而成。采集条件以表内「站点汇总」和原始记录为准：

| 项 | 值 |
| --- | --- |
| 城市 | 武汉 |
| 入住 / 退房 | 2026-10-03 → 2026-10-04 |
| 价格 | ¥250–¥400 / 晚 |
| 房型参数 | 双床房 |
| 每站上限 | 40 |
| 排序 | 距该地铁站由近到远 |
| 锚点 | 东湖以梨园地铁站为入口；武汉大学以街道口地铁站为入口 |
| 范围 | 两个锚点沿地铁各方向最多 8 站，站点去重 |

去重后共 **39** 个地铁站，全部返回 `success`，合计 **1540** 条酒店。其中房型文本含「双床」的有 **1238** 条。36 个站的页面确认了距离排序；循礼门、广埠屯、佳园路 3 站页面为智能排序，表内按采集到的距离在本地排成近到远。

工作簿有两张表：

- **酒店总表**：序号、地铁站、线路、站点说明、站内距离排名、酒店名称、房型、是否双床房、价格、星级、评分、点评数、距地铁站原文与米数、周边提示、数据状态。
- **站点汇总**：上述采集条件，以及每站的酒店数、双床房数、定位结果、查询状态和排序方式。
